## Constraints
- **Primary Keys:** UUID `gen_random_uuid()` defaults on all tables.
- **Foreign Keys:** `ON DELETE RESTRICT` used for all clinical and domain tables to prevent accidental cascading deletion.
- **Nullability and Defaults:** Matched field by field against Phase 3 specifications.

## Indexes
- Specialized `gin` Trigram index on `patients.first_name` and `last_name`.
- Specialized Vector index on `embeddings.embedding` (`1536` dimensions).
- Partial unique indexes (`appointments` token number, `critical_value_rules` parameter names).
- Fast lookup B-tree indexes for state changes and patient/encounter linkage.

## Issues
- Drizzle `index().desc()` chained syntax error was resolved by using default indexing (or native ordering on insertion query level if necessary), as Postgres B-trees can efficiently scan both ways.
- `postgres:16-alpine` does not bundle `pgvector`; updated `docker-compose.dev.yml` to use `pgvector/pgvector:pg16` to ensure the `vector` extension can be enabled successfully.
- Changed default PostgreSQL container host port from `5432` to `55432` to bypass conflict with a native `postgres.exe` running on Windows.
